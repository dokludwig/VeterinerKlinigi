## Proje Hakkında

Bu proje, Sakarya Üniversitesi Web Programlama dersi (2026-2027 Güz) proje ödevidir.
ASP.NET Core MVC (.NET 10) ile geliştirilen bir veteriner kliniği randevu ve hasta takip sistemidir.

Sistemde:
- Klinik hizmetleri (süre ve ücretleriyle) ve veteriner hekimler tanımlanır,
- Hayvan sahipleri üye olup evcil hayvanlarını ve aşı kayıtlarını takip eder,
- Hekimin müsaitliğine ve çakışmalara göre randevu alınır, randevular onaylanır veya reddedilir,
- REST API ve bir MCP sunucusu ile veriler dışarıya sunulur.

## Kullanılan Teknolojiler

ASP.NET Core MVC (.NET 10), C#, Entity Framework Core (Code First), SQLite, ASP.NET Core Identity, Bootstrap 5, ModelContextProtocol.AspNetCore
